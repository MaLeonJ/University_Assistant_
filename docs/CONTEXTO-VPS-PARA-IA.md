### Systemd Unit File Location: `/etc/systemd/system/asistente.service`
```ini

After=network.target

[Service]
```

```bash

```

### Step 3: Deploy Updated Code to VPS

```bash

ssh vps-asistente "tar -xzf ~/update.tar.gz -C ~/asistente-universitario && rm ~/update.tar.gz"
```

### Step 4: Restart and Verify Service

```bash
ssh vps-asistente "sudo systemctl restart asistente && sudo systemctl status asistente --no-pager"
```
